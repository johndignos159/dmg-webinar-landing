## How to Use This Prompt

1. **Go to Google AI Studio** → https://aistudio.google.com
2. **Click "+ new app"** → Select **Next.js** framework
3. **Paste the entire prompt above** into the chat
4. **Click "Send"** to generate
5. **Copy the code** it generates
6. **Save locally** or create GitHub repo: `dmg-webinar-landing`
7. **Test in browser** (preview locally)
8. **Push to GitHub** (if not already)
9. **Deploy to Vercel** (connect GitHub → auto-deploy)
10. **Add your custom domain** in Vercel settings
11. **Update CTA button link** to your Meta ad or webinar link
